Zoho Mail asks you to create your own DKIM selector in the Admin Console, then verify and enable it. SPF is a single include. The steps and values below follow Zoho's help pages.

On this page
  1. SPF
  2. DKIM
  3. DMARC
  4. Common problems

1. SPF

For a domain that sends only through Zoho Mail, publish on the domain itself:

v=spf1 include:zohomail.com ~all

Zoho's own examples show both ~all and -all. If several Zoho products send mail for your domain (Zoho CRM, Desk, Campaigns), Zoho documents include:one.zoho.com instead. Accounts hosted in another Zoho data center (EU, India, Australia and others) should confirm the value shown in the SPF section of their Admin Console.

Add your other senders to the same record, for example a web server:

v=spf1 ip4:203.0.113.10 include:zohomail.com ~all

2. DKIM

Create a selector

  1. Sign in to the Zoho Mail Admin Console as an administrator or super administrator.
  2. In the left menu, open Domains and select your domain.
  3. Open the Email Configuration tab and choose DKIM.
  4. Click Add, enter a selector name (for example zoho) and choose the key length, 1024 or 2048 bits. Use 2048 if your DNS host accepts it.
  5. Zoho displays the TXT value to publish.

Publish the record

TypeTXT
Host / Namezoho._domainkey (your selector followed by ._domainkey)
ValueThe full value generated by Zoho, starting with v=DKIM1;

Most DNS panels add the domain for you, so enter only zoho._domainkey as the host. If yours expects the full name, it is zoho._domainkey.yourdomain.com.

Verify and enable

Back in the Admin Console, click Verify next to the selector. Once verified, make it the default selector and enable DKIM for the domain: from then on, all outgoing mail is signed. Zoho notes that DNS changes can take 12 to 24 hours depending on TTL.

Check the published key with your selector in step 3 of the checker.

3. DMARC

TypeTXT
Host / Name_dmarc
Valuev=DMARC1; p=none; rua=mailto:dmarc-reports@yourdomain.com

Start with p=none, read the reports, then move to quarantine and reject as explained in the DMARC rollout.

Common problems

Verify fails right after publishing

DNS has not propagated, or the record was saved under zoho._domainkey.yourdomain.com.yourdomain.com. Check the exact name with the DKIM verifier before clicking Verify again.

DKIM passes but Zoho CRM or Campaigns mail fails DMARC

Each Zoho product may need its own domain authentication. Check the email authentication settings of that product, not only Zoho Mail.

Sources: Zoho Mail Help, SPF configuration and DKIM configuration.
